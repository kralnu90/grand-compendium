# Terminal Apprentice: Learn Claude Code

*A friendly tutorial game that teaches beginners how to use Claude Code.*

Lumen the helper-bot walks you through a pretend project (a website for the Paws & Whiskers pet shelter) in a safe, simulated terminal. Eight short lessons, stars for each, a cheat sheet and a certificate at the end. A free game from Kralnu Games.

**Current version: 1.0.0**

## Lessons
1. 🚪 Opening the door: `cd` into a project, start `claude`, `/exit`, `claude -c`
2. 💬 Just ask: writing clear, specific requests
3. 🛡️ May I?: permission prompts, reading diffs, saying no to surprises
4. 📎 Point at it: `@file`, `!command`, sharing screenshots
5. ⚡ Slash commands: `/help`, `/clear`, `/compact`, `/init` and CLAUDE.md
6. 🗺️ Plan before you build: Shift+Tab plan mode, Esc to stop, Esc Esc to go back
7. ✅ Check and save: tests, fixing the cause, commits, keeping secrets out of code
8. 🎓 Graduation: everything together

Phone-first, works offline, installable, no ads, free forever.
